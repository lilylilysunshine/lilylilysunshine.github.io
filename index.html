Foldable origami: CP2Seq

A paper-folding simulator and benchmark that tests whether multimodal models can plan in physical space. Given a crease pattern and a target folded shape, the model must produce the fold sequence. The simulator runs each fold and rejects illegal moves. Across 600 generated tasks, no tested model setup solved a task that needs 11 or more folds.
